# BloodBank: a social initiative

An information site about voluntary blood donation in India: who can donate, what happens on the day, which blood groups match, and why it matters. It links to [Rakt Setu](https://rakt-setugov.netlify.app), a live, free donor registry, so visitors can find a donor or sign up as one.

**Features**
- Step-by-step guide to the donation process
- Eligibility criteria based on India's NBTC donor-selection guidelines, plus a 6-question "Can I donate today?" checker that runs entirely in the browser
- Interactive blood-group matcher showing who each group can give to and receive from (red cells / whole blood)
- Myths vs facts, a WhatsApp share button, and an emergency strip (108 ambulance, e-RaktKosh blood-bank stock)
- Responsive from 360 px phones to wide desktops, light and dark mode, keyboard accessible

**Tech:** plain HTML, CSS and a little JavaScript. No build step and no framework, so it runs on GitHub Pages.

## Run it
Open `index.html` in a browser, or turn on **Settings → Pages → Deploy from branch → main / root** to publish it.

*Health information here is general guidance, not medical advice. The blood bank makes the final eligibility check.*
